//Image du projet total
<br>

The main logic of the box is : 
- The microcontroller connects to wifi
- It receives the message via the telegram token
- The heart spins until the box is open to indicate that a message arrived
- The screen displays the message when the box is opened and the servo stops
- When the box is closed, the screen stops displaying the message
- The microcontroller is ready to receive a new message
<br>
<br>


This project is a message box to offer. It features a 3D printed case, a microcontroller based on an ESP8266 that integrates wifi (Wemos D1 mini). It has a SPI screen with colours to display the messages and a limit switch as a sensor. It also has a servo moteur that makes the heart spin.
